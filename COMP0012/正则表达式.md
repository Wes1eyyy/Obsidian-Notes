Regex 里面常用的字符可以分成几类。你现在不用全背，先掌握最常考的这一批就够了。

# 1. 普通字符：直接匹配自己

```regex
a
```

匹配字母 `a`。

```regex
abc
```

匹配连续的 `abc`。

例如：

```regex
cat
```

能匹配：

```text
cat
```

不能匹配：

```text
cut
Cat
```

---

# 2. 字符集合：`[ ]`

## `[abc]`

表示：

> 匹配 a、b、c 中任意一个字符。

```regex
[abc]
```

可以匹配：

```text
a
b
c
```

不能匹配：

```text
d
ab
```

注意：它只匹配 **一个字符**。

---

## `[0-9]`

表示：

> 匹配任意一个数字。

```regex
[0-9]
```

等价于：

```regex
[0123456789]
```

---

## `[a-z]`

表示：

> 匹配任意一个小写字母。

```regex
[a-z]
```

---

## `[A-Z]`

表示：

> 匹配任意一个大写字母。

```regex
[A-Z]
```

---

## `[a-zA-Z0-9]`

表示：

> 匹配任意一个英文字母或数字。

---

# 3. 重复次数

## `?`：出现 0 次或 1 次

```regex
a?
```

表示：

```text
空字符串 或 a
```

例如：

```regex
colou?r
```

可以匹配：

```text
color
colour
```

因为 `u?` 表示 `u` 可有可无。

---

## `*`：出现 0 次或多次

```regex
a*
```

表示：

```text
空字符串、a、aa、aaa、...
```

例如：

```regex
ab*
```

可以匹配：

```text
a
ab
abb
abbb
```

因为 `b*` 表示 b 可以没有，也可以有很多个。

---

## `+`：出现 1 次或多次

```regex
a+
```

表示：

```text
a、aa、aaa、...
```

例如：

```regex
ab+
```

可以匹配：

```text
ab
abb
abbb
```

不能匹配：

```text
a
```

因为 `b+` 至少要有一个 b。

---

## `{n}`：正好出现 n 次

```regex
[0-9]{7}
```

表示：

> 正好 7 个数字。

比如学生 ID：

```regex
^u[0-9]{7}$
```

匹配：

```text
u1234567
```

---

## `{m,n}`：出现 m 到 n 次

```regex
[0-9]{2,4}
```

表示：

> 2 到 4 个数字。

可以匹配：

```text
12
123
1234
```

不能匹配：

```text
1
12345
```

---

# 4. 或：`|`

```regex
cat|dog
```

表示：

> 匹配 cat 或 dog。

可以匹配：

```text
cat
dog
```

---

通常会配合括号：

```regex
(AM|PM)
```

表示：

> 匹配 AM 或 PM。

---

# 5. 分组：`( )`

括号的作用是把一部分 regex 当成一个整体。

例如：

```regex
(ha)+
```

表示：

> `ha` 这个整体出现一次或多次。

可以匹配：

```text
ha
haha
hahaha
```

---

再比如：

```regex
(AM|PM)?
```

表示：

> AM 或 PM 这个整体可有可无。

可以匹配：

```text
AM
PM
空
```

---

# 6. 开头和结尾：`^` 和 `$`

## `^`

表示：

> 字符串开头。

## `$`

表示：

> 字符串结尾。

例如：

```regex
^cat$
```

表示：

> 整个字符串必须正好是 cat。

匹配：

```text
cat
```

不匹配：

```text
cats
my cat
cat food
```

在考试里，题目如果说 “match this format”，最好加上 `^` 和 `$`，表示完整匹配。

---

# 7. 常用简写

## `\d`

表示一个数字。

```regex
\d
```

等价于：

```regex
[0-9]
```

---

## `\w`

通常表示：

> 字母、数字、下划线。

在题目里有时会说明 `\w` 表示 `[a-zA-Z0-9]`，那就按题目定义来。

---

## `\s`

表示空白字符，例如空格、tab。

如果只想匹配普通空格，也可以直接写一个空格：

例如：

```regex
 ? 
```

中的空格就是真实空格。

---

# 8. 转义：`\`

有些字符在 regex 里有特殊含义，比如：

```text
.  ?  *  +  (  )  [  ]  {  }  |  ^  $
```

如果你想匹配它们本身，要加反斜杠。

例如：

## 匹配真正的点号 `.`

```regex
\.
```

因为单独的 `.` 在很多 regex 里表示“任意字符”。

---

## 匹配括号

```regex
\(
\)
```

---

## 匹配加号

```regex
\+
```

---

# 9. 点号：`.`

```regex
.
```

通常表示：

> 任意一个字符。

例如：

```regex
a.c
```

可以匹配：

```text
abc
a1c
a-c
```

但要小心：如果你想匹配真正的小数点，比如 email 或文件名中的 `.`，要写：

```regex
\.
```

---

# 10. 用考试题来串起来

时间题可以拆成：

```text
hour : minute optional_AM_PM
```

对应：

```regex
^(0?[1-9]|1[0-2]):[0-5][0-9]( ?(AM|PM|am|pm))?$
```

拆开看：

|片段|含义|
|---|---|
|`^`|从字符串开头开始|
|`0?`|0 可有可无|
|`[1-9]`|1 到 9 中任意一个数字|
|`|`|
|`1[0-2]`|10、11、12|
|`:`|冒号本身|
|`[0-5]`|分钟十位，只能 0 到 5|
|`[0-9]`|分钟个位，0 到 9|
|`(AM|PM|
|`?`|一个空格可有可无|
|`(...) ?`|整个 AM/PM 部分可有可无|
|`$`|到字符串结尾结束|

# 你当前最应该先记住的 10 个

|符号|作用|
|---|---|
|`[abc]`|匹配 a/b/c 任意一个|
|`[0-9]`|匹配一个数字|
|`[a-z]`|匹配一个小写字母|
|`?`|0 次或 1 次|
|`*`|0 次或多次|
|`+`|1 次或多次|
|`{n}`|正好 n 次|
|`|`|
|`( )`|分组|
|`^...$`|限定完整字符串匹配|

你先把这些掌握，COMP0012 的基础 regex 题就能开始做了。
