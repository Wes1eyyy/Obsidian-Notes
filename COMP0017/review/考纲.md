# COMP0017 考纲总览

这门课主要分两大块：

```text
1. Computability：什么问题能不能被计算？
2. Complexity：能计算的问题需要多少资源？
```

---

# 一、Computability 可计算性

## 1. Turing Machine 基础

你需要会：

```text
- 定义 Turing Machine
- 区分 accept / reject / halt / loop
- 解释 decide a language
- 简单构造 TM
```

核心概念：

```text
Recognise:
如果 w ∈ L，机器 accept；
如果 w ∉ L，机器可以 reject，也可以无限循环。

Decide:
如果 w ∈ L，机器 accept；
如果 w ∉ L，机器 reject；
并且所有输入都必须 halt。
```

---

## 2. Decidable / Recognisable / Unrecognisable

这是最核心考点。

|类型|含义|
|---|---|
|Decidable|一定停机并给出 yes/no|
|Recognisable|yes 的情况能确认，no 可能无限循环|
|Unrecognisable|连 yes 的情况也不能系统确认|

常见结论：

```text
Decidable ⇒ Recognisable

Recognisable ⇏ Decidable

如果 L 和 Lᶜ 都 recognisable，
那么 L decidable。
```

---

## 3. 经典不可判定问题

必须熟悉：

```text
ATM = {<M,w> | M accepts w}

Halting Problem = {<M,w> | M halts on w}

ETM = {<M> | L(M)=∅}
```

常见结论：

```text
ATM recognisable but undecidable

ATM complement unrecognisable

ETM undecidable and unrecognisable

ETM complement recognisable
```

---

## 4. Rice’s Theorem

考试高频。

一句话：

```text
任何关于 L(M) 的非平凡性质都是 undecidable。
```

适用条件：

```text
- 是关于语言 L(M) 的性质
- 不是关于机器语法本身的性质
- 性质非平凡：有些 TM 满足，有些 TM 不满足
```

例子：

|命题|Rice 是否适用|
|---|---|
|M accepts every string|适用|
|L(M)=∅|适用|
|M has fewer than 2 states|不适用|
|M halts on input 0|通常不直接用 Rice|

---

## 5. Mapping Reduction

非常重要。

记住方向：

```text
L ≤ L'
表示：如果能解决 L'，就能解决 L。
```

常用推理：

```text
如果 L ≤ L' 且 L' decidable，
那么 L decidable。

如果 L ≤ L' 且 L undecidable，
那么 L' undecidable。

如果 L ≤ L' 且 L unrecognisable，
那么 L' unrecognisable。
```

考试容易考反。

---

## 6. Countability

要记：

```text
所有 Turing Machines：countable

所有 strings：countable

所有 languages over {0,1}*：uncountable
```

---

## 7. Church-Turing Thesis

简洁版：

```text
任何有效可计算的算法，都可以由 Turing Machine 计算。
```

意义：

```text
所以对 TM 证明的不可计算结论，
也适用于真实编程语言。
```

# 二、Complexity 复杂性

## 1. Time / Space Complexity

需要会判断函数增长级别。

常见类别：

```text
Polynomial time:
n, n², n³, log n, n log n

Not polynomial:
2ⁿ, n^log n, n^log log n

Log space:
O(log n)
```

---

## 2. Complexity Classes

核心类：

```text
L      log-space decidable
NL     nondeterministic log-space
P      polynomial-time decidable
NP     polynomial-time verifiable
co-NP  complement of NP problems
PSPACE polynomial-space decidable
EXPTIME exponential-time decidable
```

大致包含关系：

```text
L ⊆ NL ⊆ P ⊆ NP ⊆ PSPACE ⊆ EXPTIME
```

注意：

```text
P vs NP 未知
NP vs PSPACE 未知
P ⊊ EXPTIME 已知
NL = co-NL 已知
```

---

## 3. NP 与 NP-complete

必须会解释：

```text
L ∈ NP:
给定 certificate，可以在 polynomial time 内验证。

L is NP-hard:
所有 NP 问题都可以 polynomial-time reduce 到 L。

L is NP-complete:
L ∈ NP 且 L is NP-hard。
```

---

## 4. Polynomial-time Reduction

记法：

```text
A ≤p B
```

含义：

```text
如果 B 有 polynomial-time algorithm，
那么 A 也有 polynomial-time algorithm。
```

常用推理：

```text
如果 A 是 NP-hard，且 A ≤p B，
那么 B 是 NP-hard。
```

---

## 5. 标准 NP-complete 证明模板

考试常用结构：

```text
To prove L is NP-complete:

1. Show L ∈ NP.
   给出 certificate，并说明可 polynomial-time verify。

2. Show L is NP-hard.
   从已知 NP-complete 问题 A reduce 到 L。

3. Prove correctness.
   x ∈ A iff f(x) ∈ L。

4. Conclude L is NP-complete.
```

常见问题：

```text
SAT
3-SAT
CLIQUE
Independent Set
Vertex Cover
TSP decision version
```

---

## 6. Decision / Optimisation / Search

2024 past paper 体现了这个考点。

你需要理解：

```text
Decision problem:
是否存在解？

Optimisation problem:
最优值是多少？

Search problem:
具体最优解是什么？
```

常见方法：

```text
如果有 decision solver，
可以多次调用它来找 optimal value，
再逐步 reconstruct optimal solution。
```

例如 TSP/TSDP：

```text
1. 用 binary search 找最小 k。
2. 固定或排除某些边。
3. 多次调用 decision solver。
4. 最后构造出 optimal circuit。
```

# 三、两份 Past Paper 的差异

## 差异不大

两份卷子都围绕：

```text
Computability:
TM, decidable, recognisable, Rice theorem, reduction

Complexity:
P/NP/PSPACE/EXPTIME, reductions, NP-completeness
```

所以考纲主体基本一致。

---

## 主要区别

|方面|2023|2024|
|---|---|---|
|Computability|更偏开放题、分类题|更多 MCQ 概念判断|
|Complexity|CLIQUE NP-complete 标准证明|TSDP decision → optimisation/search 构造|
|难度|模板性更强|理解性更强|
|风格|定义 + 分类 + 标准证明|概念陷阱 + 构造证明|

# 四、复习优先级

## 最高优先级

```text
1. Decidable / Recognisable / Unrecognisable
2. Rice’s Theorem
3. Mapping Reduction
4. ATM / Halting / ETM
5. P, NP, co-NP, PSPACE, EXPTIME
6. NP-complete 证明
7. Decision → Optimisation → Search
```

---

## 最容易丢分的点

```text
1. 把 reduction 方向写反

2. 把 recognisable 和 decidable 混淆

3. 乱用 Rice’s Theorem

4. 以为 P=NP 可以解决 Halting Problem

5. 以为 TSP 已经证明没有 polynomial-time algorithm

6. 忘记 NP-complete 证明必须先证明 L ∈ NP
```

# 五、一句话总结

这门课的考试核心是：

```text
先判断一个问题能不能被计算；
如果能计算，再判断它需要多少时间/空间；
如果很难，就用 reduction 证明它至少和某个已知难题一样难。
```

最重要的三条主线：

```text
Computability: decidable / recognisable / unrecognisable

Reduction: 把一个问题转化成另一个问题

Complexity: P / NP / NP-complete / PSPACE / EXPTIME
```
