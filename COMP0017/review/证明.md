# 1. 证明一个 language 是 decidable

## 使用场景

题目问：

```text
Show that L is decidable.
```

## 模板

```text
Construct a decider D for L.

On input x:
1. Perform a finite computation to check whether x satisfies the condition of L.
2. If yes, accept.
3. Otherwise, reject.

Since D halts on every input and is correct, L is decidable.
```

## 关键点

必须写：

```text
halts on every input
```

否则只能说明 recognisable，不一定 decidable。

# 2. 证明一个 language 是 recognisable

## 使用场景

题目问：

```text
Show that L is recognisable.
```

## 模板

```text
Construct a recogniser R for L.

On input x:
1. Simulate the relevant Turing machine/computation.
2. If evidence that x ∈ L is found, accept.
3. Otherwise, the machine may continue running.

If x ∈ L, R eventually accepts. Therefore L is recognisable.
```

## 常见关键词

看到这些词，通常考虑 recognisable：

```text
exists
some input
at least one string
halts on input w
accepts input w
```

# 3. 证明一个 language is undecidable

## 使用场景

题目问：

```text
Prove L is undecidable.
```

## 模板

```text
We reduce a known undecidable language A to L.

Assume, for contradiction, that L is decidable.
Since A ≤ L, a decider for L would give a decider for A.
But A is known to be undecidable.
Contradiction.

Therefore L is undecidable.
```

## 常用已知 undecidable language

```text
ATM
HALT
ETM
```

最常用句子：

```text
If L were decidable, then ATM/HALT would be decidable, contradiction.
```

# 4. 证明一个 language is unrecognisable

## 使用场景

题目问：

```text
Prove L is unrecognisable.
```

## 模板 1：用 reduction

```text
We reduce a known unrecognisable language A to L.

Assume L is recognisable.
Since A ≤ L, recognisability of L would imply recognisability of A.
But A is known to be unrecognisable.
Contradiction.

Therefore L is unrecognisable.
```

## 模板 2：用 complement

```text
Suppose L is recognisable.
If Lᶜ is also recognisable, then L would be decidable.
But L is known to be undecidable.
Therefore L cannot be recognisable.
```

或者：

```text
If L and Lᶜ are both recognisable, then L is decidable.
```

这是非常重要的定理。

# 5. 证明 Rice’s Theorem applies

## 使用场景

题目问：

```text
Does Rice’s theorem apply?
```

## 模板

```text
Rice’s theorem applies because the property is a non-trivial semantic property of the language recognised by M.

Therefore the language is undecidable.
```

## 如果不适用

```text
Rice’s theorem does not apply because the property is about the syntax/structure/halting behaviour of M, not about the language L(M).
```

## 判断标准

Rice 只管：

```text
M accepts which strings?
```

不管：

```text
M has how many states?
M halts on input w?
M runs for how many steps?
```

# 6. 证明 $(L \leq L')$

## 使用场景

题目问：

```text
Prove that L mapping-reduces to L'.
```

## 模板

```text
Define a computable function f such that:

x ∈ L iff f(x) ∈ L'.

Given input x, construct f(x) as follows: ...

The function f is computable because ...

Now:
x ∈ L
iff ...
iff f(x) ∈ L'.

Therefore L ≤ L'.
```

## 最重要句子

```text
x ∈ L iff f(x) ∈ L'
```

没有这句，证明基本不完整。

# 7. 证明 $(L^c \leq (L')^c)$

## 使用场景

2024 past paper 里考过类似：

```text
If L ≤ L', prove Lᶜ ≤ (L')ᶜ.
```

## 模板

```text
Since L ≤ L', there exists a computable function f such that

x ∈ L iff f(x) ∈ L'.

Therefore,

x ∈ Lᶜ
iff x ∉ L
iff f(x) ∉ L'
iff f(x) ∈ (L')ᶜ.

The same computable function f witnesses Lᶜ ≤ (L')ᶜ.
```

这个模板建议直接背。

# 8. 证明一个 problem belongs to NP

## 使用场景

Complexity 里常见：

```text
Show that L ∈ NP.
```

## 模板

```text
To show L ∈ NP, we give a polynomial-time verifier.

Given an input x and a certificate c:
1. Check that c has polynomial size.
2. Verify in polynomial time that c proves x ∈ L.

If x ∈ L, there exists a valid certificate c.
If x ∉ L, no certificate will make the verifier accept.

Therefore L ∈ NP.
```

## 例子：CLIQUE

```text
Certificate: a set C of k vertices.
Verifier checks that |C| = k and every pair of vertices in C is connected.
This takes polynomial time.
Therefore CLIQUE ∈ NP.
```

# 9. 证明一个 problem is NP-hard

## 使用场景

```text
Show that L is NP-hard.
```

## 模板

```text
We reduce a known NP-complete problem A to L.

Given an instance x of A, construct an instance f(x) of L in polynomial time.

Then prove:

x ∈ A iff f(x) ∈ L.

Since A is NP-complete and A ≤p L, L is NP-hard.
```

## 关键方向

一定是：

```text
known NP-complete problem ≤p new problem
```

不要写反。

# 10. 证明一个 problem is NP-complete

## 使用场景

```text
Prove L is NP-complete.
```

## 模板

```text
To prove L is NP-complete, we show:

1. L ∈ NP.
   Give a polynomial-time verifier.

2. L is NP-hard.
   Reduce a known NP-complete problem A to L in polynomial time.

Therefore L is NP-complete.
```

## 经典考试句

```text
Since L ∈ NP and L is NP-hard, L is NP-complete.
```

# 11. CLIQUE NP-complete 模板

这个非常可能考。

```text
First, CLIQUE ∈ NP. A certificate is a set C of k vertices. We can check in polynomial time that every pair of vertices in C is connected.

Next, CLIQUE is NP-hard. We reduce Independent Set to CLIQUE.

Given a graph G = (V,E), construct the complement graph G' = (V,E'), where (u,v) ∈ E' iff (u,v) ∉ E.

Then G has an independent set of size k iff G' has a clique of size k.

The construction is polynomial-time. Therefore Independent Set ≤p CLIQUE.

Since Independent Set is NP-complete, CLIQUE is NP-hard.

Therefore CLIQUE is NP-complete.
```

# 12. Decision → Optimisation 模板

2024 考过 TSDP。

## 使用场景

题目给你：

```text
Suppose there is a polynomial-time decider for the decision version.
Give a polynomial-time algorithm for the optimisation version.
```

## 模板

```text
Use the decision algorithm as an oracle.

To find the optimal value:
1. Establish a polynomially bounded search range for the value k.
2. Use binary search over k.
3. For each candidate k, call the decision algorithm to ask whether there exists a solution of value at most k.
4. Return the smallest k for which the answer is yes.

Since binary search makes polynomially many calls to a polynomial-time algorithm, the whole algorithm runs in polynomial time.
```

# 13. Decision → Search / Construct witness 模板

## 使用场景

题目要求：

```text
Find an actual optimal solution, not just the optimal value.
```

## 模板

```text
First find the optimal value k using the decision algorithm.

Then reconstruct the solution step by step:
1. Consider each possible choice/edge/variable.
2. Temporarily force or forbid that choice.
3. Use the decision algorithm to check whether an optimal solution still exists.
4. Keep the choice if the answer remains yes.
5. Continue until a complete solution is constructed.

Each step uses polynomially many calls to the decision algorithm, so the total running time is polynomial.
```

一句话理解：

```text
先用 decision oracle 找最优值，再用 decision oracle 逐步逼出最优解。
```

# 14. 证明 polynomial-time reduction

## 使用场景

Complexity 里写：

```text
A ≤p B
```

## 模板

```text
Define a function f mapping instances of A to instances of B.

We show:
1. f can be computed in polynomial time.
2. x ∈ A iff f(x) ∈ B.

Therefore A ≤p B.
```

注意比 computability 里的 mapping reduction 多了：

```text
polynomial time
```

# 15. 最后考试高频模板清单

你最该背这些：

```text
1. Show L is decidable
2. Show L is recognisable
3. Show L is undecidable by reduction
4. Show L is unrecognisable by reduction/complement
5. Show Rice’s theorem applies
6. Prove L ≤ L'
7. Prove Lᶜ ≤ (L')ᶜ
8. Show L ∈ NP
9. Show L is NP-hard
10. Show L is NP-complete
11. Decision → optimisation
12. Decision → search
```

---

一句话总结：

```text
Computability 证明主要靠：
decider / recogniser / reduction / Rice

Complexity 证明主要靠：
verifier / polynomial reduction / NP-complete / decision-to-search
```
