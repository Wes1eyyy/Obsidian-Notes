# 2. 分类模型

## 2.1 Logistic Regression 逻辑回归

### 核心定位

- 中文：逻辑回归
- 英文：Logistic Regression
- 类型：分类模型
- 生成/判别：**判别式 Discriminative**
- 凸性：**Convex**

### 速记

逻辑回归直接建模：

$$
p(y\mid x)
$$

它不是生成式模型，因为它不建模：

$$
p(x\mid y)
$$

### 必背点

- Logistic Regression 是 **discriminative classifier**。
- 常用 loss 是 cross-entropy / negative log-likelihood。
- Logistic Regression 的标准优化问题是 convex。
- 加 L2 regularisation 后仍然 convex。
- 加 L1 regularisation 后也 convex，但不可处处可导。

### 考试判断句

> Logistic Regression is discriminative because it directly models $p(y\mid x)$ rather than modelling $p(x\mid y)$ and $p(y)$.

---

## 2.2 Kernelised Logistic Regression 核逻辑回归

### 核心定位

- 中文：核逻辑回归
- 英文：Kernelised Logistic Regression
- 类型：分类模型
- 生成/判别：**判别式 Discriminative**
- 凸性：**通常仍是 Convex**

### 速记

Kernelised Logistic Regression = Logistic Regression + kernel trick。

不要看到 kernelised 就以为一定 non-convex。

### 必背点

- 用 kernel 处理非线性边界。
- 在标准形式下，对模型系数的优化通常仍是 convex。
- 本质仍然是 Logistic Regression 的判别式思想。

### 考试判断句

> Kernelised Logistic Regression remains a convex optimisation problem in the model coefficients under standard formulations.

---

## 2.3 Naive Bayes 朴素贝叶斯

### 核心定位

- 中文：朴素贝叶斯分类器
- 英文：Naive Bayes Classifier
- 类型：分类模型
- 生成/判别：**生成式 Generative**

### 速记

Naive Bayes 先建模：

$$
p(y)
$$

和：

$$
p(x\mid y)
$$

然后用 Bayes rule 得到：

$$
p(y\mid x)
$$

### 条件独立假设

Naive 的意思是：给定类别 $y$ 之后，各特征条件独立。

$$
p(x\mid y)=\prod_j p(x_j\mid y)
$$

### 必背点

- Naive Bayes 是 generative classifier。
- 它建模 class prior 和 class-conditional distribution。
- 样卷 Q3 中，如果 class conditional 是 Exponential distribution，取 log 后通常得到 linear boundary。
- 决策边界形状取决于 $p(x\mid y)$ 的形式。

### 考试判断句

> Naive Bayes is generative because it models the class prior and the class-conditional feature distribution.

---

## 2.4 Linear Discriminant Analysis, LDA 线性判别分析

### 核心定位

- 中文：线性判别分析
- 英文：Linear Discriminant Analysis, LDA
- 类型：分类模型
- 生成/判别：**生成式 Generative**

### 速记

LDA 假设每个类别下的数据服从高斯分布，并且共享协方差矩阵：

$$
x\mid y=k \sim \mathcal{N}(\mu_k,\Sigma)
$$

### 必背点

- LDA 是 generative classifier。
- 建模 $p(x\mid y)$ 和 $p(y)$。
- 不同类别共享 covariance matrix。
- 决策边界是 linear。
- LDA 和 Logistic Regression 都可能产生线性边界，但思想不同：
  - Logistic Regression 直接学 $p(y\mid x)$；
  - LDA 先学 $p(x\mid y)$ 和 $p(y)$。

### 考试判断句

> LDA is generative because it assumes Gaussian class-conditional distributions with a shared covariance matrix.

---

## 2.5 Quadratic Discriminant Analysis, QDA 二次判别分析

### 核心定位

- 中文：二次判别分析
- 英文：Quadratic Discriminant Analysis, QDA
- 类型：分类模型
- 生成/判别：**生成式 Generative**

### 速记

QDA 假设：

$$
x\mid y=k \sim \mathcal{N}(\mu_k,\Sigma_k)
$$

不同类别有不同 covariance matrix。

### 必背点

- QDA 是 generative classifier。
- QDA 建模 $p(x\mid y)$ 和 $p(y)$。
- 不同类别有不同 covariance matrix。
- 决策边界通常是 quadratic。
- 样卷 Q2 中 QDA 是 generative approach。

### 考试判断句

> QDA is generative because it models class-conditional Gaussian distributions and class priors.

---

## 2.6 Support Vector Machine, SVM 支持向量机

### 核心定位

- 中文：支持向量机
- 英文：Support Vector Machine, SVM
- 类型：分类模型
- 生成/判别：**判别式 Discriminative**
- 凸性：**常用 soft-margin SVM 是 Convex**

### 速记

SVM 直接学习最大间隔分类边界，不建模数据如何生成。

### 常见目标函数

$$
\frac{1}{2}\|w\|^2+C\sum_i \max(0,1-y_iw\cdot x_i)
$$

### 必背点

- SVM 是 discriminative classifier。
- SVM 不直接建模概率。
- SVM 不建模 $p(x\mid y)$。
- 核心概念：
  - margin
  - support vector
  - hinge loss
  - soft margin
  - parameter $C$

### Support Vector 判断

Support vectors 是：

- 落在 margin 上的点；
- soft-margin 中落入 margin 内的点；
- 被误分类但仍影响边界的点。

### 考试判断句

> SVM is discriminative because it directly learns a separating hyperplane rather than modelling the data distribution.

---

## 2.7 Decision Tree 决策树

### 核心定位

- 中文：决策树
- 英文：Decision Tree
- 类型：分类 / 回归模型
- 生成/判别：通常看作 **判别式 / 规则式**
- 凸性：**Non-convex / combinatorial**

### 速记

Decision Tree 学习 if-else 划分规则。

### 必背点

- 决策树不是 generative classifier。
- 它不显式建模 $p(x\mid y)$。
- 树结构、特征选择、分裂点选择是组合优化。
- 通常不能看作 convex optimisation。

### 考试判断句

> A Decision Tree is not a generative classifier because it learns decision rules rather than modelling $p(x\mid y)$.

# 3. 回归模型

## 3.1 Ordinary Least Squares, OLS 普通最小二乘

### 核心定位

- 中文：普通最小二乘回归
- 英文：Ordinary Least Squares, OLS
- 类型：回归模型
- 凸性：**Convex**

### 目标函数

$$
\min_w \frac{1}{2}\|y-Xw\|_2^2
$$

### 闭式解

$$
w=(X^TX)^{-1}X^Ty
$$

### 一维无截距情况

如果：

$$
\hat y = wx
$$

则：

$$
w=\frac{\sum_i x_i y_i}{\sum_i x_i^2}
$$

### 必背点

- OLS 是 convex。
- 使用 squared loss。
- 对 outliers 不鲁棒。
- 有闭式解。

### 考试判断句

> OLS is convex because the squared error objective is a quadratic function of the model parameters.

---

## 3.2 Polynomial Regression 多项式回归

### 核心定位

- 中文：多项式回归
- 英文：Polynomial Regression
- 类型：回归模型
- 凸性：**若 polynomial features 固定，则是 Convex**

### 速记

多项式回归看起来对输入 $x$ 是非线性的，但对参数 $w$ 仍然是线性的。

例如：

$$
\hat y=w_0+w_1x+w_2x^2
$$

这里对 $w$ 是线性的。

### 必背点

- 如果特征映射固定，多项式回归本质是 transformed features 上的 linear regression。
- 对参数是 convex。
- 通常使用 squared loss，所以对 outliers 不鲁棒。

### 考试判断句

> Polynomial Regression with fixed basis functions is convex in the parameters.

---

## 3.3 Ridge Regression 岭回归

### 核心定位

- 中文：岭回归
- 英文：Ridge Regression
- 类型：回归模型
- 凸性：**Convex**

### 目标函数

$$
\min_w \frac{1}{2}\|y-Xw\|_2^2+\lambda\|w\|_2^2
$$

### 速记

Ridge = squared loss + L2 penalty。

### 必背点

- Ridge 是 convex。
- L2 regularisation 会缩小权重。
- Ridge 通常不会产生严格稀疏解。
- Ridge 对 outliers 不鲁棒，因为 loss 仍是 squared loss。

### 考试判断句

> Ridge Regression is convex because both squared loss and the L2 penalty are convex.

---

## 3.4 LASSO Regression 套索回归

### 核心定位

- 中文：套索回归 / L1 正则回归
- 英文：LASSO Regression
- 类型：回归模型
- 凸性：**Convex**

### 目标函数

$$
\min_w \frac{1}{2}\|y-Xw\|_2^2+\lambda\|w\|_1
$$

### 速记

LASSO = squared loss + L1 penalty。

### 必背点

- LASSO 是 convex。
- L1 regularisation 可以产生稀疏解。
- 稀疏性意味着部分参数会变成 0。
- LASSO 可用于 feature selection。
- LASSO 不等于抗 outlier。
- 因为它的 loss 通常仍是 squared loss。

### 考试判断句

> LASSO is convex and can induce sparsity, but it is not generally robust to outliers if it uses squared loss.

---

## 3.5 Elastic Net Regression 弹性网络回归

### 核心定位

- 中文：弹性网络回归
- 英文：Elastic Net Regression
- 类型：回归模型
- 凸性：**Convex**

### 目标函数

$$
\min_w \frac{1}{2}\|y-Xw\|_2^2+\lambda_1\|w\|_1+\lambda_2\|w\|_2^2
$$

### 速记

Elastic Net = L1 penalty + L2 penalty。

### 必背点

- Elastic Net 是 convex。
- 结合 Ridge 和 LASSO。
- 既有一定稀疏性，也能缓解 correlated features 的问题。
- 不自动对 outliers 鲁棒，因为通常仍用 squared loss。

### 考试判断句

> Elastic Net is convex because it combines convex loss with convex L1 and L2 penalties.

---

## 3.6 Least Absolute Deviations, LAD 最小绝对偏差

### 核心定位

- 中文：最小绝对偏差回归
- 英文：Least Absolute Deviations, LAD
- 类型：回归模型
- 凸性：**Convex**
- 鲁棒性：**对离群点更鲁棒**

### 目标函数

$$
\min_w \sum_i |y_i-w\cdot x_i|
$$

### 速记

LAD 使用 absolute loss，不是 squared loss。

### 必背点

- LAD 是 convex。
- LAD 对 outliers 更鲁棒。
- 原因：absolute loss 是线性增长，squared loss 是二次增长。
- 样卷 Q4 中，真正抗 outlier 的是 LAD。

### 考试判断句

> LAD is more robust to outliers because the absolute loss grows linearly rather than quadratically.

# 4. 聚类与混合模型

## 4.1 k-Means Clustering k均值聚类

### 核心定位

- 中文：k均值聚类
- 英文：k-Means Clustering
- 类型：无监督聚类
- 凸性：**Non-convex**

### 速记

k-Means 同时要决定：

1. 每个点属于哪个 cluster；
2. 每个 cluster 的 centroid 在哪里。

这个联合优化问题是 non-convex。

### 必背点

- k-Means 是 non-convex。
- 对初始化敏感。
- 容易陷入 local minimum。
- 不是 generative model。
- 不直接输出概率。

### 考试判断句

> k-Means is non-convex because the cluster assignments and cluster centres are jointly optimised.

---

## 4.2 Gaussian Mixture Model, GMM 高斯混合模型

### 核心定位

- 中文：高斯混合模型
- 英文：Gaussian Mixture Model, GMM
- 类型：混合模型 / 聚类 / 密度估计
- 生成/判别：**生成式模型**
- 凸性：**Non-convex**

### 模型形式

$$
p(x)=\sum_{j=1}^k \pi_j \mathcal{N}(x\mid \mu_j,\Sigma_j)
$$

### 必背点

- GMM 是 generative model。
- GMM 通常用 EM algorithm 优化。
- mixture likelihood optimization 一般 non-convex。
- EM 只能保证局部最优。

### 考试判断句

> A mixture model is generative but its likelihood optimisation is generally non-convex.

---

## 4.3 Gamma Mixture Model Gamma 混合模型

### 核心定位

- 中文：Gamma 混合模型
- 英文：Gamma Mixture Model
- 类型：混合模型
- 生成/判别：**生成式模型**
- 凸性：**Non-convex**

### E-step responsibility

EM 的 E-step 计算 responsibility：

$$
\gamma_i^{[j]}=p(z=j\mid x^{(i)})
$$

根据 Bayes rule：

$$
\gamma_i^{[j]}=
\frac{
\pi^{[j]}p(x^{(i)}\mid z=j)
}{
\sum_l \pi^{[l]}p(x^{(i)}\mid z=l)
}
$$

如果：

$$
x\mid z=j \sim Gamma(\alpha,\beta^{[j]})
$$

且 $\alpha$ 对所有 cluster 固定，则：

$$
\gamma_i^{[j]}=
\frac{
\pi^{[j]}(\beta^{[j]})^\alpha \exp(-\beta^{[j]}x^{(i)})
}{
\sum_l \pi^{[l]}(\beta^{[l]})^\alpha \exp(-\beta^{[l]}x^{(i)})
}
$$

### 必背点

- E-step：计算 responsibility。
- M-step：更新参数。
- Responsibility 本质是 posterior cluster membership probability。
- mixture model 优化一般 non-convex。

### 考试判断句

> In the E-step, the responsibility is the posterior probability of cluster membership.

---

## 4.4 Rand Index 兰德指数

### 核心定位

- 中文：兰德指数
- 英文：Rand Index
- 类型：聚类评价指标

### 速记

Rand Index 衡量两个划分之间的一致性。

### 必背点

- 用于 clustering evaluation。
- 如果有真实标签，可以比较 cluster assignment 和 ground truth label 的一致性。
- Classification accuracy 不能直接用于聚类，因为 cluster label 本身没有固定语义。

### 考试判断句

> Rand Index is suitable for evaluating clustering because it measures the agreement between two partitions.

# 5. 降维模型

## 5.1 Principal Component Analysis, PCA 主成分分析

### 核心定位

- 中文：主成分分析
- 英文：Principal Component Analysis, PCA
- 类型：线性降维
- 凸性：通常视为特征值分解问题，而不是普通 convex optimisation 题

### 速记

PCA 找最大方差方向。

第一主成分是 covariance matrix 最大 eigenvalue 对应的 eigenvector。

### 核心公式

$$
Sv=\lambda v
$$

其中：

- $S$：sample covariance matrix
- $v$：principal component
- 最大 $\lambda$ 对应 first principal component

### 必背点

- PCA 是 linear dimensionality reduction。
- PCA 不适合 nonlinear manifold，例如 spiral data。
- PCA 对 scaling 敏感。
- PCA 前通常需要 standardisation。
- PCA 的 principal component 方向正负等价。

### 考试判断句

> PCA finds orthogonal directions of maximum variance in the data.

---

## 5.2 Probabilistic PCA, PPCA 概率主成分分析

### 核心定位

- 中文：概率主成分分析
- 英文：Probabilistic PCA, PPCA
- 类型：概率 latent variable model

### 速记

PPCA 是 PCA 的概率模型版本。

### 必背点

- PPCA 是 latent variable model。
- 假设 latent variable 通过线性映射生成 observed data。
- 噪声通常是 isotropic Gaussian noise。
- PPCA 与 PCA 密切相关。
- PPCA 对 rotation 有良好性质。
- PPCA 对 scaling 不具有同样协变性。

### 考试判断句

> PPCA is a probabilistic latent variable formulation of PCA with isotropic Gaussian noise.

---

## 5.3 Factor Analysis, FA 因子分析

### 核心定位

- 中文：因子分析
- 英文：Factor Analysis, FA
- 类型：线性 latent variable model

### 速记

Factor Analysis 也是线性 latent variable model，但噪声结构比 PPCA 更灵活。

### 必背点

- FA 是 linear latent variable model。
- FA 允许不同 observed dimensions 有不同 noise variance。
- FA 不适合明显 nonlinear manifold。
- 如果图像是 spiral，FA 不如 LLE 合适。

### 考试判断句

> Factor Analysis is a linear latent variable model and is not suitable for strongly nonlinear manifolds.

---

## 5.4 Locally Linear Embedding, LLE 局部线性嵌入

### 核心定位

- 中文：局部线性嵌入
- 英文：Locally Linear Embedding, LLE
- 类型：非线性流形学习

### 速记

LLE 适合 curved manifold / spiral data。

### 必背点

- LLE 是 nonlinear manifold learning。
- LLE 保持局部邻域结构。
- PCA 是 global linear projection。
- 如果题目图像是 spiral / curved manifold，优先想到 LLE。

### 考试判断句

> LLE is suitable for nonlinear manifold learning because it preserves local neighbourhood relationships.

---

# 6. 神经网络

## 6.1 Multi-layer Neural Network 多层神经网络

### 核心定位

- 中文：多层神经网络
- 英文：Multi-layer Neural Network
- 类型：神经网络 / 非线性模型
- 凸性：**Non-convex**
- 生成/判别：分类任务中通常是判别式

### 速记

多层神经网络优化通常非凸，因为多层参数和非线性激活函数复合在一起。

### 必背点

- 多层 Neural Network 是 non-convex。
- 表达能力强，适合复杂非线性映射。
- 容易和 learning curve 一起考。
- 如果 training error 和 validation error 都高，而且 gap 小：
  - high bias
  - underfitting
  - 模型复杂度不足
- 如果 training error 低，validation error 高，而且 gap 大：
  - high variance
  - overfitting
  - 模型过度拟合训练集

### 考试判断句

> A multi-layer neural network is generally non-convex because of the nonlinear composition of parameters across layers.

# 7. Kernel Methods 核方法

## 7.1 Linear Kernel 线性核

### 公式

$$
K(x,y)=x\cdot y
$$

### 速记

Linear kernel 是 valid Mercer kernel。

---

## 7.2 Polynomial Kernel 多项式核

### 公式

$$
K(x,y)=(1+x\cdot y)^d
$$

### 速记

Polynomial kernel 是 valid Mercer kernel。

样卷中：

$$
(1+x\cdot y)^3
$$

是 valid kernel。

---

## 7.3 RBF Kernel / Gaussian Kernel 径向基核 / 高斯核

### 公式

$$
K(x,y)=\exp(-\gamma\|x-y\|^2)
$$

### 速记

RBF kernel 是 valid Mercer kernel。

样卷中：

$$
\exp(-4\|x-y\|_2^2)
$$

是 valid kernel。

---

## 7.4 Kernel Closure Properties 核函数封闭性质

### 必背规则

如果 $K_1$ 和 $K_2$ 是合法 kernel，那么：

$$
K_1+K_2
$$

也是合法 kernel。

所以：

$$
(1+x\cdot y)^3+\exp(-4\|x-y\|_2^2)
$$

也是 valid kernel。

### 陷阱

$$
x+y
$$

不是标准 valid kernel，因为 kernel 应该输出 scalar similarity，而 $x+y$ 对向量输入通常输出向量。

# 8. 理论与泛化界

## 8.1 Hoeffding Inequality / Validation Bound

### 核心形式

对某个固定 predictor $f$：

$$
L_G(f) \leq L_V(f)+g(\delta,n_V)
$$

常见形式：

$$
L_G(f) \leq L_V(f)+\sqrt{\frac{\log(1/\delta)}{2n_V}}
$$

其中：

- $L_G(f)$：generalisation loss
- $L_V(f)$：validation loss
- $n_V$：validation set size
- $\delta$：failure probability
- $1-\delta$：confidence

### 速记

Validation error 不是 generalisation error，但可以用 bound 控制它们之间的差距。

---

## 8.2 Union Bound 并集界

### 使用场景

如果你比较了 $M$ 个模型，然后从中选 validation error 最小的一个，就需要用 Union Bound。

### 核心公式

$$
L_G(f) \leq L_V(f)+\sqrt{\frac{\log(M/\delta)}{2n_V}}
$$

其中：

- $M$：比较过的模型数量
- $\delta$：总体 failure probability
- $n_V$：validation set size

### 样卷 Q7 速记

如果：

$$
L_V(f_{Best})=0.15
$$

想保证：

$$
L_G(f_{Best})\leq 0.20
$$

则 bound gap 需要小于等于：

$$
0.05
$$

所以：

$$
\sqrt{\frac{\log(M/\delta)}{2n_V}}\leq 0.05
$$

# 9. 优化

## 9.1 Gradient Descent 梯度下降

### 更新公式

$$
x_{t+1}=x_t-\eta f'(x_t)
$$

其中：

- $\eta$：learning rate
- $f'(x_t)$：gradient

### 二次函数收敛速记

对于简单二次函数：

$$
f(x)=ax^2+bx+c
$$

二阶导为：

$$
f''(x)=2a
$$

梯度下降收敛通常要求：

$$
0<\eta<\frac{2}{L}
$$

其中 $L$ 是 gradient Lipschitz constant。

### 样卷 Q5 类型

如果：

$$
f(x)=(x-5)^2+3x
$$

则：

$$
f'(x)=2x-7
$$

更新：

$$
x_{t+1}=x_t-\eta(2x_t-7)
$$

整理：

$$
x_{t+1}=(1-2\eta)x_t+7\eta
$$

收敛要求：

$$
|1-2\eta|<1
$$

所以：

$$
0<\eta<1
$$

# 10. Learning Curve 学习曲线

## 10.1 High Bias / Underfitting

### 图像特征

| Training Error | Validation Error | Gap |
|---|---|---|
| 高 | 高 | 小 |

### 诊断

- High bias
- Underfitting
- 模型复杂度不足
- 模型学不动

### 解决方法

- 增加模型复杂度
- 增加神经网络层数 / 参数量
- 减少过强 regularisation
- 加入更有效特征

### 注意

如果题目说已经 train to convergence，则增加 epochs 通常没用。

---

## 10.2 High Variance / Overfitting

### 图像特征

| Training Error | Validation Error | Gap |
|---|---|---|
| 低 | 高 | 大 |

### 诊断

- High variance
- Overfitting
- 模型太会背训练集

### 解决方法

- 增加 regularisation
- 减少模型复杂度
- 收集更多 training data
- early stopping
- data augmentation

---

## 10.3 Good Fit

### 图像特征

| Training Error | Validation Error | Gap |
|---|---|---|
| 低 | 低 | 小 |

### 诊断

模型表现较好。

# 11. 常见对比表

## 11.1 Generative vs Discriminative

| 模型 | Generative? | Discriminative? | 速记 |
|---|---|---|---|
| Naive Bayes | ✅ | ❌ | 建模 $p(x\mid y)$ 和 $p(y)$ |
| LDA | ✅ | ❌ | 高斯，共享协方差 |
| QDA | ✅ | ❌ | 高斯，不同协方差 |
| GMM | ✅ | - | 生成数据分布 |
| Logistic Regression | ❌ | ✅ | 直接建模 $p(y\mid x)$ |
| SVM | ❌ | ✅ | 直接学分类边界 |
| Decision Tree | ❌ | ✅ / 规则式 | 学 if-else 规则 |
| Neural Network Classifier | ❌ | ✅ | 直接学输入到标签的映射 |

### 一句话速记

> 生成式先学数据怎么来：$p(x\mid y)$ 和 $p(y)$。  
> 判别式直接学怎么分：$p(y\mid x)$ 或 decision boundary。

---

## 11.2 Convex vs Non-convex

| 通常 Convex | 通常 Non-convex |
|---|---|
| OLS | k-Means |
| Ridge Regression | GMM / mixture models |
| LASSO | Neural Network |
| Elastic Net | NMF |
| Logistic Regression | Decision Tree |
| Linear SVM | Deep Learning models |
| Kernel SVM | Most latent variable likelihoods |
| LAD | - |

### 一句话速记

> 线性模型 + convex loss + convex regularisation 通常是 convex；  
> 聚类、混合模型、多层神经网络通常是 non-convex。

---

## 11.3 Outlier Robustness

| 方法 | 是否抗离群点 | 原因 |
|---|---|---|
| OLS | ❌ | squared loss 放大大误差 |
| Ridge | ❌ | 仍是 squared loss |
| LASSO | ❌ | L1 是 penalty，不是 loss |
| Elastic Net | ❌ | regularisation 不等于鲁棒 |
| LAD | ✅ | absolute loss 增长较慢 |

### 一句话速记

> 抗不抗 outlier，主要看 loss，不是看 penalty。

---

## 11.4 PCA / PPCA / FA / LLE

| 方法 | 类型 | 是否线性 | 适合 nonlinear manifold? |
|---|---|---|---|
| PCA | 最大方差线性降维 | ✅ | ❌ |
| PPCA | 概率版 PCA | ✅ | ❌ |
| Factor Analysis | 线性 latent factor model | ✅ | ❌ |
| LLE | 非线性流形学习 | ❌ | ✅ |

### 一句话速记

> 看到 spiral / curved manifold，选 LLE；看到 covariance eigenvector，选 PCA。

---

## 11.5 Learning Curve 判断

| Training Error | Validation Error | Gap | 诊断 | 解决 |
|---|---|---|---|---|
| 高 | 高 | 小 | High bias / underfitting | 增加模型复杂度 |
| 低 | 高 | 大 | High variance / overfitting | 增加正则、减少复杂度、增加数据 |
| 低 | 低 | 小 | Good fit | 不需要大改 |
| 高 | 更高 | 大 | 可能优化不足或数据问题 | 检查训练、特征、模型 |

### 一句话速记

> gap 小但都高：模型太弱。  
> gap 大：模型太会背训练集。

# 12. 最终背诵版

```text
1. Logistic Regression 是 discriminative，通常 convex。
2. Naive Bayes、LDA、QDA 是 generative，因为它们建模 p(x|y) 和 p(y)。
3. QDA 使用不同 covariance，所以边界是 quadratic；LDA 共享 covariance，所以边界是 linear。
4. OLS、Ridge、LASSO、Elastic Net、LAD、SVM 通常是 convex。
5. k-Means、GMM、Neural Network、Decision Tree 通常是 non-convex。
6. LASSO 的 L1 penalty 产生 sparsity，但不代表抗 outliers。
7. LAD 使用 absolute loss，所以对 outliers 更 robust。
8. PCA 是线性降维，第一主成分是 covariance matrix 最大特征值对应的 eigenvector。
9. LLE 适合 nonlinear manifold，例如 spiral data。
10. SVM 是 discriminative，support vectors 是 margin 上或 margin 内影响边界的点。
11. Polynomial kernel、RBF kernel、linear kernel 都是 valid Mercer kernels。
12. 两个 valid kernels 相加仍然是 valid kernel。
13. EM 的 E-step 计算 responsibility，M-step 更新参数。
14. Validation bound 比较多个模型时要用 Union Bound。
15. Learning curve 中 training 和 validation error 都高且 gap 小，是 high bias。
