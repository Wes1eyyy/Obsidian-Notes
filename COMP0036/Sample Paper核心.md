### 1. 核心概念：什么是凸优化？

简单来说，如果一个优化问题是凸的，那么它的任何**局部最优解 (Local Minimum)** 都一定是**全局最优解 (Global Minimum)**。这意味着无论你从哪里开始迭代（比如使用梯度下降），最终都能指引你到达那个“唯一的低谷”。

## 1. 核化逻辑回归 (Kernelised Logistic Regression)

- **学术定义 (Definition):** 一种判别式分类算法，利用**核技巧 (Kernel Trick)** 将线性逻辑回归扩展到高维特征空间。它通过非线性核函数（如 RBF 核）直接计算数据间的相似度，从而在原始空间中构建非线性的决策边界。
- **通俗解释:** 就像在桌面上分不开混在一起的红豆和绿豆时，给桌子加个“特效”，让豆子飞到空中（高维空间），然后在空中挥一刀（线性平面）把它们切开。
- **优化性质:** 其优化问题是**凸 (Convex)** 的，能确保找到唯一的全局最优解。

## 2. 主成分分析 (PCA - Principal Component Analysis)

- **学术定义 (Definition):** 一种线性**降维 (Dimensionality Reduction)** 技术。通过对数据的协方差矩阵进行特征值分解，提取出方差最大的方向（即主成分），旨在用更少的维度保留数据中最主要的信息。
- **通俗解释:** 像给一个 3D 雕塑拍平面照片。PCA 的任务是找一个最好的拍摄角度，让拍出来的照片能尽可能展现雕塑的轮廓和细节，不至于把重要特征重叠在一起。
- **优化性质:** 其原始优化问题涉及球面约束，属于**非凸 (Non-convex)** 优化。

## 3. k-均值聚类 (k-Means Clustering)

- **学术定义 (Definition):** 一种**无监督学习 (Unsupervised Learning)** 算法。它将数据集划分为 $k$ 个预定义的簇，通过迭代地将样本分配给最近的簇中心并更新中心位置，来最小化簇内误差平方和。
- **通俗解释:** 把一群陌生人随机分成 $k$ 个小组。先随便指派几个临时组长，让大家找离自己最近的组长站队，然后根据每组的人员位置重新选出组长，直到组长和队员都不再变动。
- **优化性质:** 存在大量局部极小值，属于**非凸 (Non-convex)** 优化，结果受初始值影响很大。

## 4. 三层神经网络 (3-Layer Neural Network)

- **学术定义 (Definition):** 一种由输入层、隐藏层和输出层组成的人工神经网络。通过非线性激活函数和层间权重的组合，该模型能够拟合极其复杂的非线性函数映射。
- **通俗解释:** 就像一个三道工序的加工厂。原材料进来，经过中间隐藏层的各种“过滤”和“特征提取”（如 ReLU 激活），最后在输出层给出一个预测结果。
- **优化性质:** 由于隐藏层和非线性激活的存在，其损失平面非常复杂，属于**非凸 (Non-convex)** 优化。

## 5. LASSO (Least Absolute Shrinkage and Selection Operator)

- **学术定义 (Definition):** 一种在线性回归基础上加入 **L1 范数正则化 (Regularization)** 的收缩方法。它通过惩罚权重系数的绝对值之和，使某些不重要的特征权重变为零，从而实现**特征选择**。
- **通俗解释:** 一个会“断舍离”的数学家。在算账时，他会惩罚那些没用的变量，把它们的权重直接砍成 0，只留下最关键的几个因素。
- **优化性质:** 其优化问题是**凸 (Convex)** 的。

## 机器学习名词解释 (Terminology)

- **凸优化 (Convex Optimization):** 一类优良的数学问题。其地形像一个大圆碗，任何地方出发都能滚到唯一的碗底（全局最优解），不会被困在半山腰的小坑里。
- **无监督学习 (Unsupervised Learning):** 机器在没有标签（没有正确答案参考）的情况下，自己通过观察数据之间的相似性来找规律（如聚类）。
- **降维 (Dimensionality Reduction):** 减少数据特征数量的过程。例如把 100 个维度的复杂数据精简成 2 个维度，以便于可视化或计算。
- **正则化 (Regularization):** 为了防止模型过度学习训练数据（过拟合）而加上的“紧箍咒”，通过限制参数的大小来提高模型的泛化能力。
- **核技巧 (Kernel Trick):** 一种聪明的数学手段，它让我们不需要真的去进行复杂的高维空间计算，就能达到在高维空间处理非线性问题的效果。

### 1. 核心概念讲解：什么是生成式方法？

你可以把分类任务想象成辨认不同种类的水果（比如苹果和橙子）：

- **生成式方法 (Generative Approach)**：它的逻辑是“**先学习每类水果长什么样**”。它会尝试为苹果建模（颜色、形状、纹理的分布），也为橙子建模。当你拿来一个新水果时，它会对比：“这个水果更像我记忆中苹果的生成概率，还是橙子的生成概率？”
    
    - **数学本质**：它学习的是联合概率分布 $P(x, y)$，或者通过学习类条件概率 $P(x|y)$ 和类先验 $P(y)$，再利用贝叶斯准则计算后验概率。
- **判别式方法 (Discriminative Approach)**：它的逻辑是“**只学习怎么区分它们**”。它不关心苹果长什么样，它只关心苹果和橙子之间的那条“**分界线**”在哪里。
    
    - **数学本质**：它直接学习条件概率 $P(y|x)$ 或者直接学习一个从输入到类别的映射函数（判别函数）。

- **A) Logistic Regression (逻辑回归)**
    
    - **引导**：回顾一下逻辑回归。它是不是直接使用 Sigmoid 函数来预测 $P(y=1|x)$ 的概率？它有没有去建模数据 $x$ 本身的分布？
- **B) Quadratic Discriminant Analysis (QDA, 二次判别分析)**
    
    - **引导**：QDA 的工作原理是假设每一类数据都服从一个**高斯分布 (Gaussian Distribution)**。它会为每一个类别计算均值和协方差矩阵，以此来描述这一类数据“长什么样”。这符合我们刚才说的“为每类数据建模”的逻辑吗？
- **C) The Support Vector Machine (SVM, 支持向量机)**
    
    - **引导**：我们在之前的讲解中提到，SVM 属于**判别函数 (Discriminant)** 方法。它追求的是最大化间隔，寻找那条最优的分界线，完全不涉及概率分布的建模。
- **D) The Elastic Net (弹性网络)**
    
    - **引导**：弹性网络实际上是一种**正则化 (Regularization)** 技术，它是 L1 (LASSO) 和 L2 (Ridge) 的结合。它通常是加在判别式模型（如逻辑回归）上的一个“紧箍咒”，用来防止过拟合，它本身并不是一种分类路径。

### 1. 明确目标：决策边界在哪里？

题目告诉我们：如果 $p(y=1|x) \ge 0.5$ 就选类别 1，否则选类别 0。

- **引导**：那么“分界线”恰好就在 $p(y=1|x) = p(y=0|x)$ 的地方。
- **贝叶斯法则推导**：根据贝叶斯定理，这等价于找到使下式成立的 $x$： $$p(x|y=1)p(y=1) = p(x|y=0)p(y=0)$$

### 2. 核心假设：朴素贝叶斯 (Naive Bayes)

题目提到这是一个**朴素贝叶斯**分类器。

- **引导**：朴素贝叶斯最核心的假设是**特征之间相互独立**。这意味着对于 2 维向量 $x = [x_1, x_2]^T$，类条件概率可以拆解为： $$p(x|y) = p(x_1|y) \cdot p(x_2|y)$$ 所以，你需要把 $x_1$ 和 $x_2$ 的概率乘起来。

### 3. 代入分布：指数分布 (Exponential)

题目给出了具体的分布公式：$p(z; \lambda) = \lambda e^{-\lambda z}$。

- **引导**：将 $x_1$ 和 $x_2$ 在不同类别下的指数分布公式代入刚才的等式中。你会得到类似这样的式子： $$(\lambda_{11} e^{-\lambda_{11} x_1} \cdot \lambda_{12} e^{-\lambda_{12} x_2}) \cdot \theta = (\lambda_{01} e^{-\lambda_{01} x_1} \cdot \lambda_{02} e^{-\lambda_{02} x_2}) \cdot (1-\theta)$$

### 4. 数学“化骨绵掌”：取对数 (Logarithm)

面对这种含有 $e$ 的指数式子，数学上最常用的处理方法就是**两边取自然对数 ($\ln$)**。

- **引导**：当你对等式两边取对数后，原本在指数位置的 $x_1$ 和 $x_2$ 会发生什么变化？
    - $\ln(e^{-\lambda x})$ 会变成 $-\lambda x$。
    - 原本的乘法会变成加法。

### 5. 观察最终方程的形式

经过对数转换和移项整理，你会得到一个关于 $x_1$ 和 $x_2$ 的方程。它看起来大概是这样的： $$( \text{常数A} ) x_1 + ( \text{常数B} ) x_2 + \text{常数C} = 0$$

    2. 如果一个方程只有 $x_1$ 和 $x_2$ 的一次项，它在坐标系里画出来会是什么形状？

这道题列出了五种回归技术，问你哪一种对训练数据中的离群点具有抵抗力：

1. Polynomial Regression (多项式回归)
2. Ridge Regression (岭回归)
3. **Least Absolute Deviations (LAD, 最小绝对偏差)**
4. LASSO
5. Elastic Net Regression (弹性网络回归)

### 1. 核心知识点：为什么模型会被离群点带偏？

要理解这道题，首先要看这些模型在优化时使用的**损失函数 (Loss Function)**：

- **平方损失 (Squared Loss)**：除了 LAD 之外，列表中的其他大部分模型（如 Ridge, LASSO, Elastic Net）在标准形式下通常都使用误差的**平方**作为损失函数。
    - **数学直觉**：如果你有一个离群点，它的误差非常大（比如 $10$），平方之后就变成了 $100$。为了减小这个巨大的数值，模型会不得不牺牲其他正常点的精度，拼命向这个离群点靠近。这就是为什么基于平方误差的模型（如 OLS, Ridge）很容易被离群点“带跑偏”。
- **绝对损失 (Absolute Loss)**：**LAD (最小绝对偏差)** 使用的是误差的**绝对值**。
    - **数学直觉**：同样是那个误差为 $10$ 的离群点，在 LAD 看来，它的代价就只是 $10$。模型会觉得：“虽然你离得远，但我也不会为了你去大幅度改变我的方向。” 这种“淡定”的态度让它对异常数据非常鲁棒。

### 2. 选项逐一拆解

- **Polynomial Regression (1)**：它本质上是带了高次项的线性回归，依然使用平方误差，因此非常容易受离群点影响。
- **Ridge (2), LASSO (4), Elastic Net (5)**：虽然它们引入了**正则化项**来防止过拟合，但它们的**预测误差项**仍然是基于平方的。正则化能让模型变简单，但并不能从根本上解决模型被极端的异常值吸引的问题。
- **Least Absolute Deviations (3)**：这是唯一一个专门为了“抗干扰”而设计的技术。它对应的是我们在之前讨论中提到的**拉普拉斯噪声假设**，其抗干扰性质就像统计学中的“中位数”比“平均值”更稳定一样。

![[Pasted image 20260425172536.png]]### 1. 目标函数分析

题目给出的函数是：$f(x) = (x - 5)^2 + 3x$。

- **引导：** 在处理梯度下降之前，我们先把它展开并简化。
    - $f(x) = (x^2 - 10x + 25) + 3x = x^2 - 7x + 25$。
- 这是一个开口向上的**二次函数**（抛物线），它的形状像一个标准的“碗”。

### 2. 找到“下山的指示牌”（梯度）

梯度下降的更新公式是：$x_{new} = x_{old} - \eta \cdot f'(x)$。

- **引导：** 请对 $f(x)$ 求一阶导数（即梯度）。
    - $f'(x) = 2x - 7$。

### 3. 理解收敛的“生死线”

在二次函数中，梯度下降是否收敛取决于学习率 $\eta$ 和函数“弯曲程度”（二阶导数）的关系。

- **核心原理：** 对于形式为 $f(x) = \frac{1}{2}ax^2 + bx + c$ 的函数，梯度下降收敛的条件是学习率 $\eta$ 必须满足： $$0 < \eta < \frac{2}{f''(x)}$$ _这里的 $f''(x)$ 是二阶导数，代表了地形的陡峭程度（曲率）。_
- **引导：** 请计算这个函数的二阶导数 $f''(x)$。
    - $f'(x) = 2x - 7 \implies f''(x) = 2$。

### 4. 计算临界值

- 根据公式，要保证收敛，学习率 $\eta$ 必须小于 $\frac{2}{2}$。
- 即：$\eta < 1$。
