# 一、AI 部分：重点考 symbolic AI / reasoning / search

Lecture notes 的 AI 部分目录包括：**Searching state spaces、Utility theory、Logic for automated reasoning、Argumentation theory、Reasoning about concepts、Reasoning about time、Reasoning about uncertainty、Machine learning**。  
但从 2025 past paper 看，今年最值得优先准备的是下面几个。

## 1. State-space search：BFS / A*

2025 第一题直接考了：

- breadth-first search 找路径
    
- A* search 找 shortest path
    
- 画 search tree
    
- 用 heuristic function (h(n))
    
- 理解 (f(n)=g(n)+h(n))
    

Lecture notes 中也明确讲了 BFS、DFS、uniform-cost、best-first 和 A*；其中 A* 的核心是选择最低 (f(n)) 的节点扩展。

**复习重点：**

|内容|要会什么|
|---|---|
|BFS|按层扩展，画 search tree|
|A*|算 (g(n), h(n), f(n))|
|heuristic|知道低估/高估对 optimality 的影响|
|search tree|能写出扩展顺序和最终路径|

---

## 2. Argumentation theory：三年稳定高频

2025 考了：

- preferred extensions
    
- grounded extensions
    
- stable extensions
    
- tree graph 中 grounded extension 是否一定是 preferred extension
    
- rebut 的 formal definition
    

这部分是高优先级，因为 2023、2024、2025 都出现过 argumentation。2025 卷中 Question 1b 和 1c 都围绕 argumentation。

**复习重点：**

|概念|要会什么|
|---|---|
|conflict-free|集合内部不能互相攻击|
|admissible|conflict-free 且能 defend 自己|
|preferred extension|maximal admissible set|
|grounded extension|minimal / least complete extension|
|stable extension|攻击所有不在集合内的 argument|
|rebut|一个 argument 攻击另一个 argument 的结论|

---

## 3. Semantic networks + First-order logic

2025 考了一个 semantic network：

- 把 is-a / is-not-a 网络转成 universally quantified formulae
    
- 加入 “Bob is a blue whale”
    
- 判断公式集合 consistent / inconsistent
    
- 推出 Bob is an aquatic creature
    
- 推出 Bob is not an aquatic creature
    
- 判断两个 argument 是否 rebut
    

这对应 lecture notes 里的 **Reasoning about concepts** 和 **Logic for automated reasoning**。

**复习重点：**

|内容|要会什么|
|---|---|
|is-a|转为 (\forall x(A(x)\rightarrow B(x)))|
|is-not-a|转为 (\forall x(A(x)\rightarrow \neg B(x)))|
|instance|Bob is a blue whale 写成 (BlueWhale(Bob))|
|consistency|能证明矛盾或给出 model|
|argument|能用公式链条推出结论|

---

## 4. Interval calculus：2025 新重点

2025 考了：

- 两个 intervals 之间的 6 种 basic relationships
    
- 画 diagram
    
- 用 meets relation 定义其中两个关系
    

这对应 lecture notes 的 **Reasoning about time**。

**复习重点：**

|内容|要会什么|
|---|---|
|before|A 在 B 之前|
|meets|A 刚好接在 B 前面|
|overlaps|A 与 B 部分重叠|
|during|A 完全在 B 内部|
|starts|A 和 B 同时开始|
|finishes|A 和 B 同时结束|
|equals|A 和 B 完全相同|

注意：课上常说 Allen interval algebra 有 13 种关系，但考试这里问的是 **6 basic relationships**，通常需要掌握它们及其 inverse 关系。

# 二、Neural Computing 部分：最稳定，几乎模板题

Neural Computing lecture notes 的目录包括：McCullough-Pitts、perceptron、MLP、Hopfield network、Reinforcement Learning、SOM 等。  
但从 2023–2025 past paper 看，真正高频考的是下面三个。

---

## 1. 单神经元计算

2025 考了：

- linear neuron
    
- McCullough-Pitts model
    
- sigmoidal firing function
    

Lecture notes 中 McCullough-Pitts / BDN 模型的核心公式是：输入乘权重后求和，再和 threshold 比较。

**复习重点：**

[  
a = \sum_i w_i x_i - s  
]

|模型|输出|
|---|---|
|Linear|直接输出 (a)|
|McCullough-Pitts|(a>0) 输出 1，否则 0|
|Sigmoid|输出 (\frac{1}{1+e^{-a}})|

---

## 2. Hopfield network

2025 考了：

- 存储两个 binary patterns
    
- 计算 Hopfield energy function
    
- 画 state transition diagram
    
- 标注 transition probabilities
    
- 解释 CAM properties 什么时候不理想
    

Lecture notes 中 Hopfield network 明确包括 CAM、energy function、update rule、weight setting rule、3-node case examples。

**复习重点：**

|内容|要会什么|
|---|---|
|weight setting rule|根据 stored patterns 算 (w_{ij})|
|thresholds|会处理 non-zero threshold|
|energy function|写出 (H(x))|
|update rule|判断状态如何变化|
|state transition diagram|8 个状态都能画出来|
|CAM|知道会有 spurious attractors、错误收敛等问题|

---

## 3. ARP / Reinforcement Learning

2025 考了：

- 给 truth table
    
- 给各 input pattern 出现概率关系
    
- 计算每个 pattern 的概率
    
- 计算 (M_{init})
    
- 计算 (M_{max})
    

Lecture notes 的 Reinforcement Learning 部分包括 stochastic learning automata、associative learning automata 和 ARP algorithm。

**复习重点：**

|内容|要会什么|
|---|---|
|pattern probability|根据比例归一化|
|(M_{init})|初始 action 概率下的期望 reward|
|(M_{max})|每个 input context 选 reward 更大的 action|
|q-table|会从 (q_0(x), q_1(x)) 读 reward probability|
